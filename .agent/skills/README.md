# Навыки электроники и встроенного ПО

Навыки проекта находятся в `.agent/skills/`. Используй профильный навык вместе с действующими `AGENTS.md` и документацией конкретного проекта. Эти материалы не заменяют datasheet, reference manual, измерения или разрешение на работу с аппаратурой.

## Навигация

| Навык | Для чего применять |
| --- | --- |
| `electronics-engineering/SKILL.md` | От требований и выбора деталей до схемы, PCB и инженерной проверки. |
| `kicad-cli/SKILL.md` | Команды KiCad для ERC/DRC и экспорта. |
| `kicad-file-format/SKILL.md` | Чтение и осторожное редактирование KiCad S-expression файлов. |
| `platformio/SKILL.md` | Структура проекта, сборка, конфигурация и отладка PlatformIO. |
| `embedded-low-level/SKILL.md` | Bare-metal MCU, старт, linker, регистры, ISR, DMA, периферия и C/C++. |
| `embedded-interfaces/SKILL.md` | Электрические интерфейсы, протоколы, измерения и устойчивые парсеры. |
| `firmware-binary-analysis/SKILL.md` | Безопасный анализ и воспроизводимые минимальные патчи существующих firmware. |
| `unknown-board-recon/SKILL.md` | Исследование неизвестных плат по фото, маркировкам и безопасной трассировке. |

## Выбор навыка

- Анализируй схему/плату целиком: `electronics-engineering` вместе с нужным навыком KiCad.
- Пиши драйвер MCU: `embedded-low-level`; если важны framing и электрический канал — также `embedded-interfaces`.
- Собирай через PlatformIO: `platformio` плюс `embedded-low-level` для аппаратно-зависимого кода.
- Исследуй HEX/BIN/ELF или существующую firmware: `firmware-binary-analysis`; запись в устройство остаётся отдельным разрешённым действием.
- Исследуй самодельную плату расширения: `unknown-board-recon`; сначала фото, маркировки и документация, без подачи питания и сигналов.

## Граница проекта

Навык `esp32p4-scope-board` намеренно не включён: он содержит назначения выводов и ограничения конкретной платы ESP32P6/JC-ESP32P4-M3 и применим только в соответствующем проекте. Не переносить его pin map на другие платы.
