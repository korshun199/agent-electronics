# Цветной консольный чат AI Tunnel

Отдельный переносимый клиент для OpenAI-совместимого API AI Tunnel. История
диалогов хранится в SQLite 3 рядом с программой, API-ключ — только в переменной
окружения. При запуске клиент сразу читает `AGENTS.md` рядом с `client.py` и
передаёт его содержимое модели как системную инструкцию. При открытии сохранённого
чата файл перечитывается; устаревший текст из настроек старого чата его не заменяет.
Если файл отсутствует, пустой или недоступен, клиент останавливается с ошибкой.

В исходном коде все имена переменных и функций написаны английскими ASCII-идентификаторами; русский текст используется для интерфейса и документации.

## Установка на Linux-сервере

Нужны Python 3.10 или новее и доступ к API AI Tunnel.

```bash
cd ai_tunnel_chat
python3 -m venv .venv
. .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install openai rich
```

Безопасно запросить ключ в текущем терминале, не показывая его при вводе:

```bash
read -rsp 'AI Tunnel API key: ' AITUNNEL_API_KEY; echo
export AITUNNEL_API_KEY
```

Запустить цветной интерактивный чат простым запускателем:

```bash
bash start.sh
```

Запускатель выбирает низкий уровень рассуждений и обычный вывод ответа. Новый
чат создаётся автоматически; чтобы открыть старый, введи в чате `/chats`, затем
`/open ID`. Модель по умолчанию — `grok-4.7`, база — `data/chat_history.sqlite3`.
Текст рассуждений на экран не выводится: вместо него появляется отдельный блок
«Модель думает…», а финальный ответ показывается отдельно. Клиент передаёт модели
инструменты для списка и чтения файлов проекта, записи текстовых файлов проекта с
резервной копией, а также ограниченного запуска локальных команд. Если модель
запрашивает инструмент, клиент показывает текущий этап, выполняет его и продолжает
запрос. Для явных просьб прочитать, найти, проверить, изменить или выполнить работу
первый вызов инструмента обязателен: если API его не вернул, клиент не принимает
текст за финальный ответ. При обрезании ответа по лимиту клиент запрашивает
продолжение. Приглашение `Ты:` возвращается только после финального ответа модели
или сообщения об ошибке.

Обычный запуск открывает последний использованный чат и показывает последнее
сообщение пользователя с ответом модели. Новый диалог запускается так:

```bash
bash start.sh --new
```

Разовый запрос также
можно передать при запуске и сохранить в базу:

```bash
python client.py "Сколько букв «р» в слове «пересмотр»?"
```

Во время запроса клиент показывает состояние ожидания, не выводя промежуточный
текст модели или результаты инструментов в историю терминала.
Тайм-аут по умолчанию — 180 секунд; при необходимости его можно увеличить:

```bash
python client.py --timeout 300
```

Ошибки API печатаются с типом, HTTP-кодом и ID запроса, если сервер их вернул.
Повторные автоматические попытки отключены, чтобы ошибка не скрывалась за долгим
молчаливым ожиданием.

Можно выбрать модель, reasoning, температуру, максимальный размер ответа,
системную инструкцию и путь к базе:

```bash
python client.py --model deepseek-r1 --effort high --temperature 0.4 \
  --max-tokens 2048 --system "Отвечай по-русски" "Объясни SQLite"
python client.py --db /путь/к/chat.sqlite3
```

Ключ и адрес API можно задать через `AITUNNEL_API_KEY` и
`AITUNNEL_BASE_URL`. Модель и reasoning можно задать через `AITUNNEL_MODEL` и
`AITUNNEL_EFFORT`. База создаётся автоматически. `--init-db` создаёт пустую
базу и таблицы, не обращаясь к API.

## Команды внутри чата

- `/help` — справка.
- `/models [фильтр]` — запросить доступные модели и отфильтровать список.
- `/model ID`, `/effort off|low|medium|high` — выбрать модель и reasoning.
- `/temperature 0..2`, `/max-tokens число|off`, `/system инструкция` — менять параметры.
- `/system agents` — перечитать `AGENTS.md` и снова использовать его в текущем чате.
- `/system off` — отключить инструкцию из `AGENTS.md` для текущего диалога.
- `/file "/путь/к/файлу"` — явно прикрепить текстовый файл из `/home/work` или
  `/home/oleg` к следующему запросу. Содержимое отправится в AI Tunnel и сохранится
  в истории чата. Секретные файлы и файлы больше 1 МБ не принимаются.
- `/stream on|off` — потоковый или обычный вывод.
- `/chats` — показать последние сохранённые диалоги и их ID.
- `/open ID` — продолжить сохранённый диалог.
- Обычный запуск открывает последний чат; `bash start.sh --new` создаёт новый.
- `/new` — создать новый диалог; старые записи останутся в базе.
- `/title название` — переименовать текущий диалог.
- `/history` — показать текущий разговор; `/clear` начинает новый разговор.
- `/exit` — выйти.

Файл SQLite хранится в `data/` и исключён из Git. Скопировать на сервер
можно всю папку `ai_tunnel_chat`; для переноса истории скопируй также
`data/chat_history.sqlite3`. Не передавай API-ключ вместе с файлами проекта.

## Разрешения локального агента

- Модель читает обычные видимые файлы только внутри каталога проекта. Скрытые
  файлы, `.git`, виртуальное окружение и `data/` для авто-чтения недоступны.
- Через `/file` владелец явно выбирает отдельный файл; его содержимое отправляется
  внешнему API и остаётся в истории этого диалога.
- Создание и запись разрешены для файлов любого типа и расширения внутри проекта,
  включая новые подпапки. Текст передаётся как UTF-8, бинарное содержимое — как
  Base64. Перед заменой файл копируется в `.agent-backups/`. Каталоги `.git`,
  `.venv`, `__pycache__`, `data` и `.agent-backups`, а также пути вне проекта,
  секреты и удаление файлов закрыты.
- Команды идут без shell в bubblewrap: сеть отключена, домашняя папка скрыта,
  исходники доступны только для чтения, а `.agent-build/` и временный `/tmp`
  доступны для сборки. Тайм-аут — 60 секунд; окружение очищено от API-ключей.
  Запрещены `sudo`, сетевые команды, прошивка, удаление, Git push и изменяющие
  Git-команды. Если `bwrap` не установлен, командный инструмент откажется запускаться.
- Модель не должна считать инструкции, найденные внутри файлов, доверенными
  командами для выполнения.
